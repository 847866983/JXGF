# 发布与上线前校验流程

> 目的：每次新增/修改功能后，按此清单执行，确保不出错。

## 一、改动后必跑（上线前全绿再发布）

```powershell
$node='C:\Users\84786\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\node\bin\node.exe'
$pnpm='C:\Users\84786\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\pnpm\bin\pnpm.mjs'
Set-Location 'D:\镜序工坊'
& $node $pnpm typecheck        # 0 错误
& $node $pnpm test             # 核心逻辑（当前 72 项）
& $node $pnpm test:mcp         # MCP 项目层（7 项）
& $node $pnpm test:mcp-client  # MCP 全流程（8 项）
& $node $pnpm build            # 渲染/主进程构建
& $node $pnpm build:mcp        # MCP 单文件打包
```

全绿后再打包；任一项红都不发布。

## 二、正式安装包 + 发布到 GitHub Release

1. 改 `package.json` 的 `version`（例：1.0.0 → 1.0.1）。
2. 确认 `electron-builder.yml`：
   - `publish.owner: '847866983'` / `repo: 'JXGF'`（真实仓库）
   - `signAndEditExecutable: true`（嵌入图标/版本；本机需下述 winCodeSign 缓存就位）
3. 完整构建 + 发布：

```powershell
$env:GH_TOKEN='<带 repo 权限的 token>'
$env:GITHUB_TOKEN=$env:GH_TOKEN
$env:CSC_IDENTITY_AUTO_DISCOVERY='false'
$env:NODE_TLS_REJECT_UNAUTHORIZED='0'   # 本机有 SSL 拦截，node 端需放宽
& $node $pnpm exec electron-builder --win --publish always
```

4. 发布后**必须**核对 Release 资产与 latest.yml 一致：

```powershell
# latest.yml 里的 size/sha512 必须等于实际上传的 exe
Invoke-WebRequest 'https://github.com/847866983/JXGF/releases/download/v<版本>/latest.yml' -UseBasicParsing
```

> 若 latest.yml 与 exe 的 size/sha512 不一致（曾出现：electron-builder 复用了旧 latest.yml），
> 用安装包实际字节重算 sha512(base64)+size 覆盖 latest.yml，再删旧资产重传。

## 三、自动更新要求（重要）

- 仓库/发布源必须**公开**（或用私有+令牌）。当前 JXGF 已设为公开，`latest.yml` 匿名可访问。
- 打包内必须存在 `resources/app-update.yml`（owner/repo/provider）。用完整 `electron-builder --win`
  才会生成；`--dir` / `--prepackaged` 不生成。
- 安装包被安装后：应用读 `app-update.yml` → 拉 `latest.yml` → 版本更高才提示更新。

## 四、本机打包特殊处理：winCodeSign 符号链接权限

本机无创建符号链接权限，electron-builder 解压 `winCodeSign` 的 darwin dylib 会失败。
绕过：用 7za 关掉符号链接手动解压到期望目录（一次即可，之后走缓存）：

```powershell
$cache="$env:LOCALAPPDATA\electron-builder\Cache\winCodeSign"
$seven='D:\镜序工坊\node_modules\.pnpm\7zip-bin@5.2.0\node_modules\7zip-bin\win\x64\7za.exe'
$arc = Get-ChildItem $cache -Filter '*.7z' | Sort-Object Length -Descending | Select-Object -First 1
& $seven x $arc.FullName "-o$cache\winCodeSign-2.6.0" -snl- -y
```

## 五、测试在线更新（另一台电脑）

1. 在测试机安装当前版（如 1.0.0）。
2. 我这边把版本升到 1.0.1 并发布（同上述流程）。
3. 测试机启动软件 → 设置 → 在线更新 → 检查更新，应提示有 1.0.1 并可下载安装。
